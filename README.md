# Orbit — AI Tools Dashboard

A responsive frontend learning project built with **HTML, CSS, JavaScript, React, Bootstrap 5** and Vite.

## Features
- Bento-inspired dashboard layout
- Responsive desktop and mobile design
- Search AI tools by name, category or description
- Filter by category
- Add/remove favorite tools
- Open tool websites in a new tab
- Copy a starter prompt
- Mobile navigation menu

## Run on your computer

1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local address shown by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
```

Vite creates the production website in the `dist` folder.

## Deploy on Vercel
1. Upload this project to a GitHub repository.
2. Sign in to Vercel and import that repository.
3. Vercel normally detects Vite automatically.
4. Use `npm run build` as the build command and `dist` as the output directory.
5. Deploy.

## Important
This is a frontend-only demo. It does not have a backend, user accounts, or cloud-saved favorites. Favorites are temporary and reset when the page reloads. The tool cards link to their official websites.
